# 태권도 레벨 테스트

상황별 질문으로 알아보는 나의 태권도 내공 및 레벨 진단 웹 애플리케이션 서비스입니다.

## 🥋 주요 특징
- **7가지 레벨 & 세부 단계**: 흰 띠, 노란 띠, 파란 띠, 빨간 띠, 유품자(1~4품), 유단자(1~5단), 선수, 사범님, 관장님
- **국기원 데이터 기반 상위 % 표시**: 국기원 2026년 6월 품·단 등록 및 응시자 현황 통계 연동
- **원클릭 결과 카드 이미지 다운로드**: 고화질 PNG 결과 인증서 카드 저장 기능 (HTML5 Canvas)
- **카카오톡 결과 공유하기**: 카카오 SDK 연동 피드 공유 기능
- **15개 상황별 퀴즈**: 동료 격려, 위기 대처, 수련 의지, 도복의 의미 등 몰입감 넘치는 문항 구성
